# Legal Summariser

A Streamlit-based app that summarizes long legal judgments using a transformer model (T5).  
You can choose summary length and export results.

## Features
- Upload legal PDFs
- Choose summary length: brief, moderate, detailed
- Get high-quality summaries using HuggingFace Transformers

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
